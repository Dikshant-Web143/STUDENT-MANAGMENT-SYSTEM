# 🎓 Student Management System

A Java-based desktop application developed using **Java Swing** for managing student-related information efficiently.

## 📌 Project Description

The Student Management System is designed to simplify the management of student records in an educational institution. The application allows administrators to manage student information, courses, attendance, marks, results, and fee records through a user-friendly graphical interface.

This project demonstrates important Java programming concepts including Object-Oriented Programming, classes, objects, collections, event handling, GUI development, and data management.

## ✨ Features

* 🔐 Admin Login System
* 👨‍🎓 Add Student Records
* ✏️ Update Student Information
* 🗑️ Delete Student Records
* 🔍 Search Students by Name or Roll Number
* 📚 Course Management
* 📊 Attendance Management
* 📝 Marks and Result Management
* 🎯 Automatic Grade Calculation
* 💰 Fee Management
* 📈 Automatic Attendance Percentage Calculation
* 🖥️ User-Friendly Java Swing Interface
